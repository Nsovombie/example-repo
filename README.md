# Shoe Inventory

A small JavaScript program that manages a shoe shop's stock using objects.

## What it does

- Uses a `Shoes` constructor to make shoe objects with a name, product code, quantity and value per item
- Stores five shoes in an array
- Can search for a shoe by name or product code
- Finds the shoe with the lowest and the highest value per item
- Edits all four properties of a shoe
- Sorts the shoes from lowest to highest value per item
- Shows all the results as neat tables in the console with `console.table()`

## How to run it

You need [Node.js](https://nodejs.org/) installed. Then run:

```
node inventory.js
```
